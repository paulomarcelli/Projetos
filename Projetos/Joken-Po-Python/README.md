## 📌 Sobre o Projeto
O **Joken-Po** é um projeto desenvolvido em Python para praticar lógica de programação, estruturas condicionais, entrada de dados e interação com o usuário pelo terminal. O jogador escolhe entre pedra, papel ou tesoura, enquanto o computador faz uma escolha para definir o resultado da partida.

## 🚀 Como Executar
Entre na pasta do projeto e execute o arquivo principal:

```bash
cd Projetos/Joken-Po-Python
python jokenpo.py
```

No Windows, também pode ser necessário utilizar:

```bash
python3 jokenpo.py
```
