# Prompt para Google Stitch (Etapa 3 da skill)

Use este prompt se quiser gerar variações visuais rápidas para comparar com o Figma. É opcional, porque o protótipo oficial já existe.

```
Crie 6 telas para uma aplicação web de acompanhamento escolar bimestral (Ensino Fundamental) voltada a coordenação, professores e famílias, em português do Brasil.
Estilo: educacional, moderno e acolhedor, com cantos arredondados (12–20px), sombras suaves e um acento de cor por vez.
Paleta: tinta #1B3A4B (menu e cabeçalhos), teal #0B7285 (secundária), céu #74C0FC, azul de ação #2A5CFF (só o botão principal), sol #FFC94A, menta #5FD4A8, fundo #F3F9FA, texto #0B2E3C.
Fontes: Bricolage Grotesque (títulos) / Plus Jakarta Sans (texto) / JetBrains Mono (médias).
Tela 1 — Home pública: hero escuro com print do painel e um celular com o relatório da família; "como funciona" em 4 etapas (abre o bimestre, professor registra, coordenação revisa, família acompanha); cartões dos 3 perfis; faixa de segurança/LGPD; CTA.
Tela 2 — Escolha de perfil: "Como você acessa o KFKA?" com 3 cartões (coordenação, professor, responsável) e arte escura à esquerda.
Tela 3 — Painel do professor: anel de progresso do 3º bimestre, alertas de registros devolvidos com o comentário da coordenação, cartões das turmas com barra de status.
Tela 4 — Novo acompanhamento: aluno, turma, disciplina, bimestre, média 0–10, tags em pílulas selecionáveis, descrição com contador, botões Salvar rascunho / Pré-visualizar / Enviar para revisão.
Tela 5 — Revisão (coordenação): stepper Rascunho→Enviado→Em revisão→Publicado, média editável, texto do professor, linha do tempo de auditoria, botões Devolver e Publicar.
Tela 6 — Painel da família (celular): seletor do filho, abas de bimestre, destaque "novo relatório publicado", cartões por disciplina com a nota, botão "Li e estou ciente", barra de abas inferior.
Status sempre com texto + ícone + cor: Rascunho (cinza), Enviado (teal), Em revisão (âmbar), Publicado (verde), Devolvido (terracota), Cancelado (cinza escuro).
Referências de estilo: escolha de papel antes do login (Seesaw); celular com balões no hero (ClipEscola); cartões de números sobre o print (Lyceum).
```
