# Blender Skills — origem e uso

O repositório incorpora o pacote [Blender Skills](https://github.com/arjun988/blender-skills), versão 1.3.0, de Arjun Singh, sob licença MIT. As skills estão em `.claude/skills/` e foram adicionadas sem substituir as skills Blender que já existiam no projeto. A licença original está em `docs/skills/BLENDER-SKILLS-LICENSE`.

Para trabalhos 3D no Blender, Sofia começa pela `design-skills` conforme sua regra principal e, em seguida, usa `blender-director` para escolher as skills especializadas pertinentes. O pacote também oferece padrões de execução via Blender MCP, mas isso exige a conexão do MCP com uma instância Blender ativa; a presença dos arquivos de skill não significa que essa conexão esteja configurada ou disponível.

Origem: https://github.com/arjun988/blender-skills (tag/version declarada no repositório: 1.3.0).
