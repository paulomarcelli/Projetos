# Joken-Po em Python

Projeto de um jogo de **Joken-Po (Pedra, Papel e Tesoura)** desenvolvido em Python.

## Tecnologias

- Python 3

## Como executar

Coloque o arquivo principal do jogo nesta pasta e execute pelo terminal:

```bash
python jokenpo.py
```
