# Karol · Turnê no Brasil 2027 (projeto acadêmico)

Landing page fictícia, feita para a atividade de Gestalt. Sem vínculo com Karol Sevilla ou sua equipe;
o formulário não envia nada (só mostra a confirmação).

## Rodar
```
npm install
npm run dev
```
Build: `npm run build` (sai em `dist/`).

## O que vem do pacote Sopro
- `src/motion/ink.js` e `hero.js`: a tinta que segue o mouse e mostra as letras infladas (cores trocadas para marinho e azul-bebê).
- `src/motion/fisica.js`: os balões que caem e dá para arremessar.
- `src/motion/contato.js`: o KAROL do rodapé que foge do cursor.
- `src/motion/smooth.js`: rolagem suave (Lenis).
- `public/infla/cheio.webp` + `caixa.json`: "KAROL" inflado, renderizado no Blender com `arquivos/scripts/infla.py`.

## Gestalt aplicada
Centralização e simetria (seção Fotos: arco no centro, polaroides em equilíbrio), figura e fundo (tinta que revela as
letras infladas), fechamento (anel tracejado aberto e o logo KS), hierarquia (KAROL → frase → botão), regra dos terços
(texto no terço esquerdo da seção A turnê), proximidade e similaridade (itens numerados, fotos iguais, pílulas),
continuidade (fotos em degraus), leitura em Z e região comum (formulário dentro de um cartão), pregnância (formas simples
e duas cores com branco).
