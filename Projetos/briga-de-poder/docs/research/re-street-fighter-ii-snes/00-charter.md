# Charter: Street Fighter II SNES
Date: 2026-10-31

| Item | Value |
|---|---|
| Goal | Estudar Street Fighter II (SNES), jogado na página retrogames.cz, para orientar as Fases 2 a 6 do BRIGA DE PODER: regras de luta do gênero, estrutura de partida, controles, entrega do jogo no navegador (teclado, controle virtual de toque, netplay). Não é um clone: o BRIGA DE PODER tem identidade, personagens e golpes próprios. |
| Requested by | Usuário do projeto BRIGA DE PODER ("faca o uso do /reverse-engineering-saas neste site https://www.retrogames.cz/play_304-SNES.php , é o joguinho de luta, vai ajudar nas proximas fases") |
| Scope | Mecânicas documentadas publicamente (rounds, tempo, vida, controles, golpes especiais, hitstun, bloqueio, arremesso, combos); fluxo de partida; o carregamento do emulador web (EmulatorJS), observado sem iniciar o jogo. As telas do site em volta do jogo ficam fora: as telas do BRIGA DE PODER são as já criadas na Fase 1 (pedido do usuário). |
| Out of scope | Rodar a ROM, baixar a ROM, extrair sprites, sons, músicas, textos ou dados do jogo; copiar nomes de personagens ou golpes; números de quadros específicos do jogo original. |
| Clone target market | Brasil, público geral de navegador (desktop e celular). O "clone" aqui é o BRIGA DE PODER, que reaproveita convenções do gênero, não o conteúdo do jogo estudado. |
| Priorities | P1 regras de combate e de partida (Fase 2); P2 entradas, combos e entrega Web/toque (Fase 3); P3 modo solo e netplay (Fases 5 e 6). |
| Mode | attended |
| Environment level | L4 Observe only |
| Write authorization | none (pedido de estudo; nenhuma conta, nenhuma escrita) |
| KB language | Português do Brasil (IDs e rótulos de campo em inglês) |
| Terms of service | A página não exige conta. Ela carrega uma cópia não licenciada de um jogo comercial da Capcom (`EJS_gameUrl = 'SNES/Street_Fighter_II.zip'`) [obs EV-004]. Por isso o estudo não executou o emulador nem baixou o arquivo: tudo sobre o jogo vem de fontes públicas. Ver BR-002. |
