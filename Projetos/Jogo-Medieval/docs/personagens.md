# A Coroa de Sal — elenco (para aprovação)

> Todos os personagens são originais. Estilo: desenho animado 2D, cores chapadas, contorno escuro fino,
> cabeça grande. Marque cada um como ✅ aprovado, ✏️ mudar ou ❌ cortar.
