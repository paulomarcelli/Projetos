## 📌 Sobre o projeto
O **Gemini Chatbot** é um projeto pessoal criado para desenvolver um chatbot simples utilizando a API do Google Gemini. A proposta é praticar integração com APIs, envio de mensagens e construção de interações com Inteligência Artificial.

A implementação do chatbot será adicionada posteriormente pelo autor. A chave da API deverá ser configurada de forma segura no ambiente de execução e não deve ser publicada no repositório.

## 🛠️ Tecnologias utilizadas
| Tecnologia | Utilização |
|---|---|
| Python 3 | Desenvolvimento do chatbot e da lógica do projeto |
| Gemini API | Processamento das mensagens e geração das respostas |
| Git / GitHub | Versionamento e organização do código |

## 🚀 Como executar
A implementação e as instruções de execução serão adicionadas quando o código do chatbot for importado para esta pasta.

Antes de executar o projeto, configure a chave da API do Gemini como variável de ambiente. Não insira a chave diretamente no código nem no README.
