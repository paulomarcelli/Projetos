# How It's Built: free starter skill (Morrow Studio)

Claude Code makes a first draft of a vertical 3D "How It's Built" short in Blender, from an
"If you… But… So you… This is a…" script.

1. Install **Blender** (free, blender.org) and **Claude Code**.
2. Unzip this folder and open it in Claude Code.
3. Type: `Read SKILL.md, then help me make a How It's Built short.` Then use the 3 prompts in SKILL.md.

**The full kit** adds what makes it go viral: the look, the mistake checks, sound, thumbnails and a review against a
viral video. It's in Morrow Studio: **skool.com/morrow**
